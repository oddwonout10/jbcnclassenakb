# Sample Circulars

This directory contains synthetic placeholder files used during development. Real school circulars should be stored in Supabase Storage and **must not** be committed to the repository.

## How to use

1. Drop sample PDFs here when running ingestion locally.
2. Set `SUPABASE_URL` and related credentials in `.env` before testing uploads.
3. Avoid committing production data—replace with sanitized or mock files only.
